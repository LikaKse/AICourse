# День 11 — результаты эксперимента (gemini)

Модель: `gemini-3.5-flash-lite`; окно краткосрочной памяти: 6; сценарий: 15 реплик (30 сообщений); вопросов: 15.
Источник токенов: Gemini: count_tokens (contents, без system instruction) и usage_metadata.
Реальные ответы Gemini.

## 1. Что сохранено в каждом слое после сценария

| Слой | Файл | Содержимое |
|---|---|---|
| Краткосрочная память | `short_term.json` | 30 сообщений, в промпт — последние 6 |
| Рабочая память | `working_memory.json` | задача #1, статус in_progress; поля: goal, deadline, budget, status, next_step; ограничений 1, результатов 1 |
| Долговременная память | `long_term.json` | 8 фактов (user: 7, accepted_proposal: 1) |

Долговременная память:

- `name` = Лика — *user*, name
- `city` = Нячанг — *user*, location
- `os` = macOS — *user*, environment
- `no_docker` = никакого Docker — *user*, constraint
- `response_style` = кратко — *user*, preference
- `language_preference` = Python — *user*, preference
- `openweather_limit` = бесплатный ключ OpenWeather ограничен 1000 запросами в день — *user*, knowledge
- `test_framework` = pytest — *accepted_proposal*, preference

Рабочая память:

```json
{
```
