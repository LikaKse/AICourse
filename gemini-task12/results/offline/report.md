# День 11 — результаты эксперимента (offline)

Модель: `gemini-3.5-flash-lite`; окно краткосрочной памяти: 6; сценарий: 15 реплик (30 сообщений); вопросов: 15.
Источник токенов: FakeClient: детерминированный фейковый счёт (3 на часть + 1 на слово), НЕ токены Gemini.
Офлайн: ответ = эхо контекста, поэтому «верно» означает «нужный факт попал в промпт».

## 1. Что сохранено в каждом слое после сценария

| Слой | Файл | Содержимое |
|---|---|---|
| Краткосрочная память | `short_term.json` | 30 сообщений, в промпт — последние 6 |
| Рабочая память | `working_memory.json` | задача #1, статус in_progress; поля: goal, deadline, budget, status, next_step; ограничений 1, результатов 1 |
| Долговременная память | `long_term.json` | 9 фактов (user: 7, accepted_proposal: 1, assistant_proposal: 1) |

Долговременная память:

- `name` = Лика — *user*, name
- `city` = Нячанг — *user*, location
- `project` = учебный скрипт на Python: собирает курсы валют и погоду — *user*, other
- `os` = macOS — *user*, environment
- `no_docker` = не использовать Docker ни для разработки, ни для запуска — *user*, constraint
- `answer_style` = кратко и с примерами кода на Python — *user*, preference
- `openweather_limit` = бесплатный ключ OpenWeather — 1000 запросов в день — *user*, knowledge
- `test_framework` = pytest — *accepted_proposal*, decision
- `scheduler` = launchd (системный планировщик macOS) — *assistant_proposal*, decision

Рабочая память:

```json
{
 "task_id": 1,
 "status": "in_progress",
 "goal": "еженедельный отчёт по курсам валют в формате Markdown",
 "deadline": "20 ноября",
 "budget": "не больше 5 USD на платные API",
 "next_step": "написать тесты для build_report",
 "constraints": [
  "отчёт помещается на одну страницу"
 ],
 "results": [
  "функция load_rates готова: читает курсы из JSON за неделю"
 ]
}
```

## 2. Правила записи в действии: отклонённые операции

| Сообщение | Слой | Ключ | Причина |
|---|---|---|---|
| 19 | WM | `priority` | поле 'priority' не входит в рабочую память (допустимо: goal, deadline, budget, status, next_step, constraints, results) |
| 21 | WM | `results` | неподтверждённое предложение ассистента — не данные задачи |
| 9 | LT | `test_framework` | вопрос пользователя — не факт |
| 15 | LT | `current_task` | данные текущей задачи — место в рабочей памяти, не в долговременной |
| 17 | LT | `deadline` | данные текущей задачи — место в рабочей памяти, не в долговременной |
| 23 | short_term | `note` | краткосрочную память пишет только код |

Записано: WM 8, LT 9; неудачных вызовов менеджера памяти: 0.
