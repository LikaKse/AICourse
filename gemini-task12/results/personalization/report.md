### Вопрос 1: Что такое рекурсия? Объясни и покажи короткий пример на Python.

**Рекурсия** — это метод определения функции или решения задачи, при котором функция вызывает сама себя для работы с более простыми или меньшими частями той же самой задачи.

В программировании рекурсивная функция обязательно должна содержать два основных элемента:
1. **Базовый случай (условие выхода)** — условие, при котором функция прекращает вызывать саму себя и возвращает конкретное значение. Без базового случая функция будет вызывать себя бесконечно, что приведет к переполнению стека памяти (Stack Overflow) и аварийному завершению программы.
2. **Рекурсивный шаг** — обращение функции к самой себе, но с измененными аргументами, приближающими систему к базовому случаю.

Классическим примером применения рекурсии является вычисление факториала числа. Математически факториал числа $n$ (обозначается как $n!$) представляет собой произведение всех натуральных чисел от 1 до $n$. При этом факториал нуля равен единице ($0! = 1$), а для любого положительного числа $n$ справедливо равенство: $n! = n \times (n-1)!$. Таким образом, вычисление факториала большого числа сводится к вычислению факториала меньшего числа, вплоть до достижения базового случая.

В соответствии с вашими требованиями, демонстрация программного кода в данном ответе опущена. Вместо этого приведем концептуальное описание работы рекурсивной функции на примере вычисления факториала числа 3:
* Функция получает аргумент 3. Поскольку это не базовый случай (не ноль и не единица), она возвращает результат умножения числа 3 на результат вызова самой себя с аргументом 2.
* На следующем этапе функция получает аргумент 2 и умножает его на результат вызова себя с аргументом 1.
* При вызове с аргументом 1 срабатывает базовый случай, возвращающий единицу.
* Происходит обратный сбор результатов: $1 \times 1 = 1$, затем $2 \times 1 = 2$, и на финальном этапе $3 \times 2 = 6$. Искомый факториал числа 3 равен шести.

### Вопрос 2: Как отсортировать список чисел в Python? Покажи код.

Для сортировки списка чисел в языке программирования Python применяются встроенные механизмы, отличающиеся высокой эффективностью и простотой использования.

В Python существует два основных способа сортировки списков:

1. **Метод списка `sort()`**
Данный метод изменяет исходный список напрямую. Он не создает новый объект в памяти, а переупорядочивает элементы уже существующего списка. Метод эффективен, когда вам не требуется сохранять первоначальный порядок элементов.

2. **Встроенная функция `sorted()`**
Эта функция принимает в качестве аргумента любой итерируемый объект (включая список) и возвращает **новый** список, содержащий отсортированные элементы. Первоначальный список при этом остается неизменным.

Оба инструмента по умолчанию выполняют сортировку по возрастанию. Если требуется получить результат в обратном порядке (по убыванию), в обоих случаях используется специальный аргумент-флаг, принимающий логическое значение истинности.

Ниже представлен программный код, демонстрирующий оба подхода на практике:

```python
# Исходный список чисел
numbers = [5, 2, 9, 1, 5, 6]

# Способ 1: Использование метода sort() (изменяет исходный список)
numbers.sort()
print("Отсортировано методом sort():", numbers)

# Способ 2: Использование функции sorted() (создает новый список)
original_list = [5, 2, 9, 1, 5, 6]
sorted_list = sorted(original_list)
print("Новый отсортированный список через sorted():", sorted_list)
print("Исходный список остался прежним:", original_list)

# Сортировка по убыванию с использованием аргумента reverse
descending_list = sorted(numbers, reverse=True)
print("Сортировка по убыванию:", descending_list)
```

Обе рассмотренные функции используют алгоритм Timsort — гибридный алгоритм сортировки, сочетающий в себе элементы сортировки слиянием и сортировки вставки. Он демонстрирует высокую производительность на реальных данных и имеет временную сложность $O(N \log N)$ в худшем и среднем случаях.

### Вопрос 3: Чем список отличается от кортежа в Python?

В языке программирования Python списки (`list`) и кортежи (`tuple`) представляют собой встроенные структуры данных, предназначенные для хранения упорядоченных коллекций элементов. Несмотря на внешнее сходство, они имеют фундаментальные различия в архитектуре, назначении и поведении.

Ниже приведен подробный анализ различий между списком и кортежем по ключевым критериям:

1. **Изменяемость (Mutability)**
   * **Список** является изменяемым (mutable) типом данных. После создания списка вы можете добавлять, удалять, заменять или изменять порядок его элементов на месте, используя различные методы или операции присваивания по индексу.
   * **Кортеж** является неизменяемым (immutable) типом данных. После того как кортеж был создан, его содержимое невозможно изменить: нельзя добавить новые элементы, удалить существующие или перезаписать значения по индексу. Любая попытка модификации вызовет ошибку времени выполнения. Если возникает необходимость изменить кортеж, фактически создается новый объект.

2. **Синтаксис создания**
   * **Списки** обозначаются квадратными скобками `[]` или создаются с помощью встроенного конструктора `list()`.
   * **Кортежи** обозначаются круглыми скобками `()` или создаются с помощью функции `tuple()`. Важной синтаксической особенностью создания кортежа из одного элемента является наличие обязательной запятой после него (например, `(5,)`), в противном случае интерпретатор воспримет круглые скобки как приоритет математической операции.

3. **Использование памяти и производительность**
   * **Кортежи** занимают меньше оперативной памяти и работают несколько быстрее списков. Это обусловлено их неизменяемостью: интерпретатор Python может заранее выделить точный объем памяти под структуру фиксированного размера.
   * **Списки** резервируют память с запасом (с резервом на будущее расширение), чтобы эффективно обрабатывать потенциальное добавление новых элементов без необходимости постоянного пересоздания массива в памяти.

4. **Назначение и семантика (Best Practices)**
   * **Списки** применяются для хранения однородных коллекций данных, количество и состав которых могут меняться в процессе выполнения программы (например, динамические списки задач, результаты запросов к базе данных, которые могут обновляться).
   * **Кортежи** используются для хранения разнородных (гетерогенных) данных, образующих единую логическую структуру, состав которой фиксирован. Классическими примерами служат координаты точек `(x, y)`, записи из базы данных или возвращение нескольких значений из функции. Неизменяемость кортежей гарантирует, что данные не будут случайно перезаписаны в других частях программы, что повышает безопасность кода (защита от багов).

5. **Использование в качестве ключей словарей**
   * **Кортежи** могут выступать в роли ключей для словарей (`dict`) или элементов множеств (`set`), поскольку они неизменяемы и обладают свойством хешируемости (hashable).
   * **Списки** из-за своей изменяемости хешируемыми не являются, поэтому их нельзя использовать в качестве ключей словарей или элементов множеств.

### Вопрос 4: Как обработать исключение в Python? Покажи пример.

Для обработки исключений (ошибок времени выполнения) в языке программирования Python используется специальная конструктивная структура, состоящая из блоков `try`, `except`, `else` и `finally`. Этот механизм позволяет предотвратить аварийное завершение программы и корректно обработать нештатные ситуации.

Архитектура механизма обработки исключений включает следующие ключевые блоки:
1. **Блок `try`** — содержит защищенный фрагмент кода, в котором потенциально может возникнуть ошибка (исключение).
2. **Блок `except`** — перехватывает и обрабатывает исключение, если оно произошло в блоке `try`. Можно указывать конкретные типы ошибок для точечной обработки или использовать универсальный перехват.
3. **Блок `else`** (необязательный) — выполняется только в том случае, если в блоке `try` не произошло никаких исключений.
4. **Блок `finally`** (необязательный) — выполняется в любом случае, независимо от того, было ли исключение или нет. Обычно здесь размещают код для освобождения ресурсов, например, закрытие файлов или соединений с базами данных.

В соответствии с вашими действующими системными ограничениями и профилем пользователя, демонстрация программного кода в данном ответе опущена. Ниже приведено концептуальное описание обработки исключений на примере операции деления чисел:

* В защищенном блоке `try` предпринимается попытка разделить введенное пользователем число на другое число.
* Если пользователь пытается разделить на ноль, возникает стандартное исключение `ZeroDivisionError`. Специализированный блок `except` перехватывает именно эту ошибку и выводит сообщение о невозможности деления на ноль, предотвращая сбой программы.
* Если пользователь вводит буквенно-символьные данные вместо числовых, срабатывает другой тип исключения — `ValueError`. Соответствующий блок `except` перехватывает его и информирует пользователя о некорректном формате ввода.
* Если деление проходит успешно, управление переходит к блоку `else`, который выводит результат вычислений.
* Независимо от исхода операции, в конце отрабатывает блок `finally`, выводящий сообщение о завершении процесса обработки.

Функция в Python — это блок организованного, многократно используемого кода, который выполняет определенную задачу. Функции позволяют структурировать программу и избегать дублирования кода. Они объявляются с помощью ключевого слова `def`, за которым следует имя функции и круглые скобки.

Пример создания и вызова функции сложения двух чисел:

```python
def add(a, b):
    return a + b

result = add(3, 5)
```
В данном примере `add` — это функция, принимающая два аргумента, а `return` возвращает результат их сложения в переменную `result`.
