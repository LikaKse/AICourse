## 1. Что сохранено в каждом слое после сценария

| Слой | Файл | Содержимое |
|---|---|---|

| Долговременная память | `long_term.json` | 9 фактов (user: 7, accepted_proposal: 1, assistant_proposal: 1) |

Долговременная память:

- `name` = Лика — *user*, name
- `city` = Нячанг — *user*, location
- `language` = Python — *user*, environment
- `os` = macOS — *user*, environment
- `no_docker` = отказ от использования Docker — *user*, constraint
- `response_style` = кратко и с примерами кода на Python — *user*, preference
- `openweather_limit` = бесплатный ключ OpenWeather ограничен 1000 запросами в день — *user*, knowledge
- `test_framework` = pytest — *accepted_proposal*, preference
- `scheduler` = launchd или cron — *assistant_proposal*, alternative
